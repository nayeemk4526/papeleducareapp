# পাপেল এডু-কেয়ার (Papel Edu-Care) - Premium Educational Platform

## Overview
A vibrant, fully responsive Bengali educational platform featuring modern animations, dark/light mode support, and premium UI/UX design using React, Tailwind CSS, Framer Motion, and Shadcn UI.

---

## Core Features

### 🎨 Design System & Theme
- **Color Palette**: Electric Blue (#3B82F6), Deep Purple (#7C3AED), Neon Cyan (#22D3EE), Vibrant Pink (#EC4899)
- **Dark/Light Mode Toggle**: Persistent theme switching with smooth transitions
- **Typography**: Bengali-optimized fonts with excellent readability

### ⏳ Global 2-Second Loader
- Custom loading animation displaying "পাপেল এডু-কেয়ার লোডিং হচ্ছে..."
- Animated progress bar with gradient effects
- Triggers on every page navigation and refresh

## Technical Highlights
- Framer Motion for all animations (entrance, hover, page transitions)
- Embla Carousel for touch-friendly sliders
- Intersection Observer for scroll-triggered animations
- Local storage for theme persistence
- Fully responsive breakpoints (mobile-first approach)
